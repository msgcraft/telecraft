# Telecraft

마인크래프트 자바 에디션 서버의 채팅을 모바일 환경에 어울리게 제작한 앱입니다.
꾸준한 유지보수와 다양한 기능 업데이트, 앱 디자인을 계획 중입니다.

**구글 플레이 스토어와 애플 앱스토어의 앱 등록 과정 중에 있습니다. 정식 출시를 기대해 주세요**

이 페이지는 안드로이드 시험판 다운로드 페이지 입니다.

- 스붕이들 필독 사항 -
1. 포탈 서버의 '코드발급용 공원' 서버에 접속 후
2. /msgcraft android 명령어를 입력하시면 
3. Pro를 영구적으로 활성화 할 수 있는 리딤코드를 발급 받을 수 있습니다.
4. 발급 받은 Pro 리딤코드는 스토어 정식 출시 후에도 유효합니다.

## 설치

1. 오른쪽의 **Releases**에서 맨 위 버전의 `telecraft-….apk`를 받습니다.
2. 받은 파일을 열고, 안드로이드가 물으면 "이 출처 허용"을 켠 뒤 설치합니다.
3. 정품 마인크래프트(Microsoft) 계정으로 로그인합니다.

새 버전이 나오면 앱이 알려 주고, 받아서 설치 화면까지 열어 줍니다.
(설정 > 앱 정보 > 업데이트 확인)

## 안내

- 문의: 앱의 설정 > 앱 정보 > 고객지원
